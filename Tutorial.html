1 Fill an existing form

Pick a form, make your choices, export

ProForm comes with ready-to-use example forms. Select one from the sidebar, work through the dropdowns, then export your completed answers in the format your workflow needs.

Save once required fields are filled
The Save button lights up once every required field has an answer. Click it to name and store your fill in the Filled Forms library — that's also what unlocks the Export button next to it. More on both in the next chapter.
Built-in forms are locked — duplicate to customise
Example forms can't be edited directly. Use Duplicate to customise (in the form's header menu) to make a personal editable copy with all the same fields.
Required fields are marked
Any field marked required shows a REQ badge and will alert you if you try to export before answering it.

2 Build a new form

Create a form field by field

Switch to the Build a Form tab to design your own forms from scratch. Add dropdown fields, section headlines, and info notes — then arrange them in any order by dragging.

Dropdown fields: first line is the field name, the rest are options
Type the field name in the Field name box, then list each dropdown option on its own line in the Options box. Add as many options as you need — click Expand next to the box to edit a long list in a larger window.
Headlines divide the form into sections
Add a Headline between fields to create a labelled section break. It appears in bold when the form is filled, and is included in exported output — unless every field under it is left blank, in which case that empty section's headline is left out of the export too.
Info boxes show guidance text — not exported
Use an Info box to add instructions or context that the user reads while filling the form. Info boxes are shown in italics and are intentionally excluded from exported output.

3 Import from text

Turn a Word document into a form in minutes

If your form already exists as a Word document, you don't need to rebuild it by hand. Paste the text (or load the file directly) and the import wizard does the rest — walking you through a three-step process.

1Paste or load text
2Preview & clean up
3Confirm each field
Accepts .txt, .doc, and .docx files
Click Build from import to load a file directly — no copy-paste needed. Paragraph text is imported, along with bold and italic formatting — a bold line followed by its own options is auto-tagged as a dropdown block, a bold line standing alone is auto-tagged as a Headline, and an italic paragraph is auto-tagged as an Info box, all in Cleanup. Tables and images are not imported.
Double-click any line in Cleanup to edit it
Fix a typo, rename an option, or reword a field name directly in the Cleanup screen before building. Press Enter to save the edit, Escape to cancel.
Merge imports into an existing form
At the final step you choose whether to create a new form or add these fields into one you've already started — useful for building a long form in several passes.
Import a whole section as a subform
In Cleanup, select a section's heading plus the field paragraphs under it and click Subform instead of Dropdown block. The Confirm field step for that selection lets you edit the subform's name and its own fields, then pick which already-confirmed field and answer reveals it — the fields inside get parsed the same way as the rest of the import, just one level down.

4 Conditional logic

Show or hide fields based on what's selected

A conditional rule makes certain fields appear or disappear depending on a user's choice in another field. This keeps forms short — only the relevant questions are shown for any given answer.

The core idea: one answer controls what else appears
A rule always starts the same way — pick a field with options, pick one of its answers, then decide what that answer does. From there it can do up to three things: show or hide other fields, narrow which options a shown field offers, or reveal a whole subform. Rules live on the same page (ProForm forms are single-page) and each one is anchored to one field's one answer. A field inside a subform gets its own rules too, scoped to that subform's other fields, so multi-step "if this, then that" chains are built one link at a time — subforms themselves stay one level deep, though, so a field inside one can't trigger a further nested subform.
Set up rules in the form builder
Open a form in the Build tab and expand any dropdown field — a Conditional logic section appears automatically at the bottom, the same way for a field inside a subform. Click a pill button for the answer you want to build a rule around, then click Show or Hide next to each other field to set what happens. If a field you show has its own dropdown options, a nested checklist lets you narrow those down too. Click Expand to do this in a larger window. Once a form has any rules, a Logic overview link appears above the field list — it draws every rule as a flow diagram, with a line from each trigger field to each of its answers and on to whatever that answer shows, hides, narrows, or reveals (including subforms, and each subform's own rules nested underneath it). Click any box to jump straight to it.
Subforms: a whole nested field group triggered by one answer
You can attach a subform to any dropdown option — a set of additional fields that appears only when that option is chosen. Ideal for "if Corporation, ask for registration details" scenarios. The fastest way in: inside that option's rule, click + New subform for "…" to create and link it in one step, instead of adding a subform separately and linking it by hand.
Premium feature
Conditional logic and subforms are available during the 30-day trial and require activation afterward. All other form-filling and plain-text export is always free.

5 Saving & exporting

Keep your work safe, share it anywhere

ProForm gives you several ways to save your forms and export completed answers — from a single-click session save to a full library backup you can carry between devices.

Save, then Export — two separate buttons
Save (top-right) lights up once every required field is filled, and stores the fill in your Filled Forms library. Export next to it only unlocks after that Save — and re-locks the moment you change anything, so re-save first if you keep editing.
Left an optional field blank? Export still asks first
Clicking Export with unfilled optional fields shows a warning listing what will be skipped — choose Export anyway to continue. Required fields are never skippable this way; Save is blocked until they're complete.
Plain text export is always free
Completed answers are copied as clean, readable text — field name followed by the selected answer, one per line. Word and PDF export require a Premium activation.
Activation keys are device-specific
To get a key, click Enter licence key in the top bar, then Buy ProForm for an instant emailed key, or Request key by email to arrange it manually. Either way, the key is cryptographically tied to your device and only works on the machine you bought it for.
Back up your form library before switching devices
Go to the Build tab sidebar and click Back up my forms — this saves a .json file with all your custom forms. Use Restore backup on any device to bring them back.

6 Multi-select fields

Let users tick more than one answer

A multi-select field presents a list of checkboxes instead of a single dropdown. Users can check as many options as apply — including a free-text "Other (specify)" box, on by default for new fields. Useful any time the answer isn't one thing.

Switch any field between Dropdown and Multi-select
Open the field card in the builder and click the Multi-select toggle at the top. Your options list stays exactly as-is — nothing needs to be retyped.
"Other (specify)" adds a free-text box automatically
New fields have this toggle on by default in the builder, so the fill-form view already includes an Other (specify) row at the bottom of the checkbox list — checking it reveals a text input for a custom answer. Turn the toggle off if you want to strictly limit answers to the listed options.
All checked answers are included in the export
When you export, the multi-select field shows the field name followed by a comma-separated list of every checked option — including any "Other" text. Works in all three export formats.
Premium feature. Multi-select fields are available during the 30-day trial and require a Premium activation key afterward.

7 Folder sync & backup

Keep your forms safe and portable

ProForm stores everything in your browser by default. Two features let you go further: My Forms folder links a real folder on your disk so forms are saved as individual files you can open, back up, and move around. Library backup exports everything as a single file you can restore anywhere.

Folder sync saves each form as its own .json file
Once linked, every save, rename, or delete in ProForm is mirrored to that folder on disk — filled sessions too, in a "Filled Sessions" subfolder ProForm creates automatically. You can also drop an existing ProForm .json file into the folder and it will be picked up on the next visit.
Library backup works on every browser
Folder sync requires Chrome or Edge (File System Access API). The backup/restore option is your safety net everywhere else — Safari, Firefox, iOS. Always take a backup before switching devices.
Restoring a backup never overwrites existing forms
Forms already in your library are matched by ID. Any that already exist are silently skipped — only genuinely new forms from the backup file are added. Safe to run repeatedly.

8 Libraries & activation

Your form libraries and getting a licence

ProForm keeps two live libraries in the top bar — one for forms you've built, one for sessions you've filled. A 30-day trial unlocks everything; after that, a one-time key keeps premium features permanently.

Deleting a form or a saved fill — no folder digging required
Both dropdowns have a small ✕ on each entry. Deleting a form asks you to confirm first (it can't be undone); deleting a saved fill happens right away. Either way, if a "My Forms" folder is linked, the matching file on your computer is removed too — you never need to go delete it there by hand.
Trial → one-time key, no subscription
A 30-day free trial starts automatically when ProForm first opens — all features fully unlocked, nothing counted. When it ends, click Enter licence key in the top bar → Buy ProForm for an instant emailed key, or Request key by email to arrange payment manually. Paste the key into the dialog and click Apply key. Once entered, the key is permanent, device-specific, and validates fully offline from then on.
ProForm won't let you lose unsaved work
If you navigate away from the builder with unsaved changes, ProForm shows a save dialog first. While a form is being filled with unsaved answers, it goes further: the tab bar, both library dropdowns, the sidebar form list, other saved sessions, and search all lock until you click Save (once required fields are complete) or the Discard button next to it — either one clears the block and lets you move on.
